# Titre du skill

## Pourquoi ce skill existe

Le problème qu'il résout pour Idris et le critère de réussite (à quoi Idris reconnaît un bon résultat).

## Avant de commencer

Lire ces références (chemins relatifs au dossier de ce skill) :

- `../../references/partage/regles-ecriture.md` : fiabilité, typographie, données personnelles.
- `../../references/partage/voix-idris.md` : seulement si le skill écrit au nom d'Idris.
- `../../references/<reference-du-plugin>.md`

Si le skill travaille pour un client ou un organisme, lire aussi le `CLAUDE.md` de son espace (`espaces/<nom>/CLAUDE.md`) : c'est là que vivent le contexte et les contraintes propres au client.

## Workflow

### 1. Rassembler la matière
### 2. Produire
### 3. Vérifier
### 4. Rendre la main (résumé court en français)

## Cas limites

- Information manquante : la demander ou s'arrêter et le signaler, ne jamais deviner.
