# Séance 2 · Céline LAFITTE · Textes à coller

À envoyer dans le chat de la visio au moment de chaque exercice.

---

## Pratique 1 · Relire tes instructions

Dans une nouvelle conversation, hors projet. Colle ensuite tes Instructions pour Claude actuelles et la liste de tes projets sous le texte.

```
Voici mes Instructions pour Claude, puis la liste de mes projets.

Classe chaque phrase de mes instructions dans l'une de ces trois catégories :
1. Vaut pour toutes mes conversations : elle reste dans mes Instructions pour Claude.
2. Propre à une activité : dis-moi dans quel projet elle doit aller.
3. Une méthode pour produire un livrable : elle deviendra un skill.

Ensuite, propose une version courte de mes Instructions pour Claude, avec seulement la catégorie 1.
N'ajoute rien et n'invente rien : si une phrase est ambiguë, pose-moi la question.

MES INSTRUCTIONS :
<coller ici>

MES PROJETS :
<coller ici>
```

## Pratique 2 · Le prompt de création du skill

Dans une nouvelle conversation. Joins ta trame de synthèse et un exemple de synthèse réussie, anonymisés.

```
Je veux créer un skill : « synthèse de séance de bilan ».

Il part de mes notes brutes de séance et rédige la synthèse de séance, destinée à la personne que j'accompagne. Je la relis toujours avant de l'envoyer.

Pose-moi tes questions une par une, en attendant ma réponse avant la suivante : les étapes de ma méthode, le format, le ton, les pièges à éviter.

Appuie-toi sur la trame et l'exemple que je joins (anonymisés).

Règles à inscrire dans le skill :
- N'ajoute rien qui ne soit pas dans mes notes.
- Signale par [À vérifier] tout ce que tu déduis.
- Termine par la liste des points que je dois relire avant envoi.
- Données anonymisées seulement : signale tout nom ou détail identifiant avant de continuer.
```

## Pratique 2 · Les notes fictives (déjà utilisées en séance 1)

Situation inventée pour l'exercice : aucune personne réelle.

```
Bilan de compétences, séance 3 sur 15. Bénéficiaire : « Mme R. », 44 ans.
Assistante de direction dans une PME industrielle (80 personnes) depuis 12 ans.
Veut évoluer : office manager ? RH ? Peur de « repartir de zéro ».
Fierté : a piloté seule le déménagement du siège (planning, prestataires).
Aime organiser, être le point de contact. Évite les conflits frontaux.
Valeurs citées : fiabilité, reconnaissance, équilibre vie perso (2 enfants).
Outils : Excel avancé, Sage. Organise les réunions du CSE (convocations, PV).
À faire pour la séance 4 : deux enquêtes métier (office manager, assistante RH).
```

## Pratique 2 · Corriger le skill

```
Modifie mon skill « synthèse de séance de bilan » pour que <ce qui ne va pas>.
```

## Bonus · Le questionnaire de valeurs

Dans le projet « Bilans », nouvelle conversation. Garde le public qui correspond à ton coaché.

```
Crée un questionnaire pour mes coachés, en trois parties : mes valeurs, mes talents, mes compétences techniques.

Public : [attachés de direction / personnes en recherche d'emploi].

Questions ouvertes et échelles de 1 à 5, sans jargon RH. 20 minutes maximum à remplir.

Livre-le en fichier Word, prêt à remettre au coaché.
```
