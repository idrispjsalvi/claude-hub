## Exercice 1 · Les notes fictives

Situation inventée pour l'exercice : aucune personne réelle.

```
Bilan de compétences, séance 3 sur 15. Bénéficiaire : « Mme R. », 44 ans.
Assistante de direction dans une PME industrielle (80 personnes) depuis 12 ans.
Veut évoluer : office manager ? RH ? Peur de « repartir de zéro ».
Fierté : a piloté seule le déménagement du siège (planning, prestataires).
Aime organiser, être le point de contact. Évite les conflits frontaux.
Valeurs citées : fiabilité, reconnaissance, équilibre vie perso (2 enfants).
Outils : Excel avancé, Sage. Organise les réunions du CSE (convocations, PV).
À faire pour la séance 4 : deux enquêtes métier (office manager, assistante RH).
```

## Exercice 1 · Le prompt naïf (premier chat)

```
Fais une synthèse de ces notes.
```

## Exercice 1 · Le prompt SCPIC (deuxième chat)

```
[S] Tu es une consultante en bilan de compétences expérimentée.

[C] Je mène un bilan de compétences en 15 séances. Voici mes notes brutes de la séance 3 :
<coller les notes>

[P] La synthèse est destinée à la bénéficiaire. Je la relis avant de la lui envoyer.

[I] Rédige une synthèse de séance en 4 parties :
1. Ce que nous avons travaillé
2. Les valeurs repérées
3. Les compétences transférables
4. Le travail à faire pour la prochaine séance

[C] Une page maximum. Vouvoiement, phrases courtes, ton bienveillant.
N'ajoute rien qui ne soit pas dans mes notes. Signale par [À vérifier] tout ce que tu déduis.
```

## Exercice 2 · Le prompt d'interview

```
Tu es un consultant spécialisé dans la configuration d'assistants IA pour les coachs professionnels.

Je suis coach professionnelle indépendante. Je veux écrire ma « base de contexte de coach » : un document d'une page que ChatGPT lira avant chaque échange, pour connaître mon métier sans que je le répète.

Pose-moi 10 questions, UNE PAR UNE, en attendant ma réponse avant la suivante. Couvre : qui je suis, mes publics, mes accompagnements (bilan, coaching, formation), mes méthodes et outils, mes livrables et leurs formats, mon ton, ce que je ne veux jamais, mes règles de confidentialité.

Ensuite, rédige le document avec ces 8 rubriques titrées. Une page maximum. N'invente rien : si une information manque, écris [À compléter].
```

## Exercice 2 · Les instructions du projet

À coller dans : projet « Bilans de compétences » › ••• › Paramètres du projet › Instructions.

```
Tu es l'assistant de Céline, coach professionnelle.
Appuie-toi toujours sur le fichier « Base de contexte de coach » de ce projet.
1. Données anonymisées seulement : signale tout nom ou détail identifiant avant de continuer.
2. N'invente rien : marque [À vérifier] ce que tu déduis.
3. Termine par les points que je dois relire avant envoi.
```

## Exercice 2 · Le résumé pour les instructions personnalisées

Dans une conversation où la base de contexte est disponible, puis à coller dans : Paramètres › Personnalisation › Instructions personnalisées.

```
Résume ma base de contexte en moins de 1 500 caractères : qui je suis, mes publics, mon ton, mes règles de confidentialité. Garde seulement ce qui vaut pour toutes mes conversations, pas ce qui est propre aux bilans de compétences.
```
