## Pratique 1 · Partie A · Extraire les questions de ton artefact

Dans la conversation où tu as créé ton outil d'autocoaching.

```
Je veux transformer cet outil d'autocoaching en Google Form.

Liste toutes ses questions, dans l'ordre, et pour chacune :
1. le texte exact de la question ;
2. le type de question Google Forms à utiliser : réponse courte, paragraphe,
   échelle de 1 à 5, choix multiples ou cases à cocher ;
3. les choix proposés, s'il y en a.

Ajoute en tête deux questions :
- « Ton code coaché » (réponse courte, obligatoire) ;
- une question d'accord, obligatoire : « J'accepte que mes réponses soient
  utilisées par Céline Lafitte pour préparer mon accompagnement. »

Propose aussi une phrase d'introduction pour le formulaire : ce que je collecte et pourquoi.
N'ajoute aucune autre question et n'invente rien : si une question de l'outil est ambiguë,
pose-moi la question.
```

## Pratique 1 · Partie B · Lire les réponses et rédiger la cartographie

Dans ton projet de coaching. Adapte le nom du Sheets et les rubriques à ta propre cartographie.

```
Dans mon Google Drive, ouvre le Google Sheets « Check-up - réponses ».
Lis uniquement la ligne du code coaché C-01.

Rédige sa cartographie selon ma trame :
- ses valeurs ;
- ses talents ;
- ses motivations ;
- ses freins ;
- des pistes d'évolution.

Règles :
- n'invente rien : chaque point s'appuie sur une réponse, que tu cites entre guillemets ;
- écris [À vérifier] après chaque déduction qui n'est pas dite mot pour mot ;
- termine par la liste des points que je dois vérifier avant de restituer au coaché.
```

Puis, une fois le rendu validé :

```
On crée un skill « Cartographie de coaché » à partir de ce rendu.
Montre-moi d'abord sa structure (nom, description, étapes, règles) avant de l'enregistrer.
```

## Pratique 2 · Ta feuille de route

Dans ton projet de coaching.

```
Aide-moi à écrire ma feuille de route d'une page pour mes outils de coach.

Mes publics : <coachés, bilans de compétences, attachés de direction, organismes...>

Pour chaque public, pose-moi les questions une par une :
- que remplit-il ?
- que reçoit-il ?
- revient-il plusieurs fois, ou une seule ?

Puis classe chaque public sur l'une de ces quatre marches :
1. artefact Claude (le client a un compte Claude) ;
2. formulaire + tableur (une seule fois, sans compte) ;
3. interface hébergée (un outil à mon image, sans compte) ;
4. plateforme (des comptes, un espace et un historique par client).

Termine par ma plateforme cible en six points (qui se connecte, ce qu'il voit, ce qu'il
remplit, ce que fait l'IA, ce que je valide, où vivent les données) et par la première
étape réaliste pour la semaine prochaine. N'invente rien sur mon activité : demande-moi.
```
